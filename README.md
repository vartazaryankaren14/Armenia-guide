# Armenia-guide

Путеводитель по Армении для Telegram Mini App.

## Фотографии

Основные снимки находятся в `images/places/`, три файла на место: `<ID>_1.webp`, `<ID>_2.webp`, `<ID>_3.webp`. Источники и лицензии — в [PHOTO_SOURCES.md](PHOTO_SOURCES.md).

21 ноября 2026 года исправлены фотографии восьми мест: ущелья Касах, Макараванка (Тавуш), Цахкадзора, Дилижана, Степанаванского дендропарка, храма Гарни, монастыря Гегард и озера Цовер. Для каждой из восьми карточек использованы три конкретных файла Wikimedia Commons, взятых из [photo-curation-reviewed.json](photo-curation-reviewed.json). Статус выполнения — [PHOTO_CURATION_RESULT.json](PHOTO_CURATION_RESULT.json).

Перед публичным использованием остальных фотографий необходимо проверить их соответствие объекту и требования лицензии. Нельзя представлять картинки, созданные ИИ, как документальные фотографии реальных достопримечательностей.

Резервная ветка до этих изменений: `backup/photos-before-curation-2026-11-21`.

Важно: повторный запуск старой задачи автоматического поиска фотографий может перезаписать вручную исправленные кадры.

Проверить изображения по областям: [photo-review.html](photo-review.html). Все 8 выбранных групп успешно обработаны, см. PHOTO_CURATION_RESULT.json.

24 ноября 2026 года карточка «Парк Победы и Мать Армения» дополнена сведениями об аттракционах, мемориале, аллеях и озере «Аревик». Её фотогалерея содержит четыре отдельные реальные фотографии Wikimedia Commons, включая два снимка аттракционов; коллажи не используются.
