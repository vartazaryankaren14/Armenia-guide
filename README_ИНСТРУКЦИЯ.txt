ARMENIA GUIDE — обновление Telegram Mini App

Готово: 77 мест из последней таблицы, группировка по областям, галереи, поиск, избранное, Яндекс Карты.

ДЛЯ ОБНОВЛЕНИЯ СУЩЕСТВУЮЩЕГО САЙТА
1. Откройте https://github.com/vartazaryankaren14/Armenia-guide
2. Загрузите НОВЫЙ файл index.html в корень репозитория, заменив старый.
3. Папка images с файлами hero-armenia.png, garni.png, geghard.png должна находиться рядом с index.html. Если фотографии уже есть, можно загрузить только index.html.
4. Проверьте сайт https://vartazaryankaren14.github.io/Armenia-guide/
5. Откройте @ArmeniaGuideBot > меню, проверьте поиск, области, избранное и карты.

ВАЖНО: Ссылки фото 1–3 импортированы из вашей таблицы. Доступность каждой внешней картинки и право на публикацию по лицензии отдельно не подтверждены. Для фотографии есть ссылка на страницу Wikimedia Commons.
Цены и часы — значения из таблицы, они не обновляются автоматически.
